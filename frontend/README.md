# Fintech project Frontend
React + Vite customer-facing frontend for the Fintech project FastAPI application.

## Run
```powershell
npm install
npm run dev
```
Open http://localhost:3000

Backend default: http://127.0.0.1:8000

## Pages
Dashboard, Accounts, Cards, Transfers, Exchange, Wallet, Trading, AI Agents, KYC, Transactions, Settings.

## Notes
The UI calls supported backend endpoints and uses demo fallback data when the local API is unavailable. This is an assessment/educational UI, not production banking software.
